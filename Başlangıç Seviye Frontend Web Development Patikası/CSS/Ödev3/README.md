# Google Ana Sayfa Klonu

Bu proje, Patika.dev Frontend Web Development Patikası kapsamında Google ana sayfasının HTML ve CSS kullanılarak oluşturulmuş bir klonudur.

## Proje İçeriği

- HTML yapısı ve semantik etiketler
- CSS ile stil ve düzen
- Responsive tasarım
- Flexbox kullanımı

## Nasıl Görüntülenir

index.html dosyasını bir web tarayıcısında açarak projeyi görüntüleyebilirsiniz.
